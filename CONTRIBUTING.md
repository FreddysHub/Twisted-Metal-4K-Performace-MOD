# Help test TM4K

Include mod/base commits, game serial/update/PPU hash, CPU/GPU/driver/OS, level,
vehicle, route/camera, cache state, reproduction steps and observed result.
Small screenshots and redacted log excerpts help.

Do not attach game files, firmware, saves, controller identifiers, credentials
or full multi-gigabyte captures. Review captures and arrange sharing separately.
Preserve a working baseline and vary one parameter group per test.
A setup PASS is not a graphics/FPS test.

Explain changed code and compile/shader checks. Distinguish offline previews
from live tests. Preserve licenses, credit authors, disclose AI assistance and
human review, and do not claim tests not performed. No automated upstream
communication is part of this publication.
